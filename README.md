## 简体中文

### 📖 项目介绍
这是一个趣味且硬核的 **AI 认知能力与修仙境界测试** H5 互动应用。通过精心设计的场景化自测题，帮助你快速评估自己在 AI 时代的理解深度、应用段位以及工具驾驭能力。

单文件 HTML 设计（已内嵌所有视觉资源与样式），无需任何编译和后端依赖，开箱即玩。

### 💡 灵感来源：Karpathy AI 认知漏斗 (The AI Cognition Funnel)
本项目灵感源于 Andrej Karpathy 等 AI 领军人物对人机协作认知演进的洞察：
1. **练气期·初窥门径**：把 AI 当作高级搜索引擎或偶尔聊天的智能问答助手；
2. **筑基期·初涉法度**：掌握 Prompt 工程，在日常工作中用 AI 辅助写作、翻译与基础编码；
3. **金丹期·驭器自如**：熟练将多模型与专业工具（MCP、CLI、代码解释器、知识库）组合工作；
4. **元婴期·法由心生**：深度构建 Agent 工作流，将业务流程自动化解构为多智能体协同；
5. **化神/渡劫期·天人合一**：深刻理解模型原理、认知边界与认知架构，重构组织与个人的生产力范式。

你现在修到了哪一境？来测一测便知！

### 🚀 本地打开方式
1. 克隆本仓库到本地：
   ```bash
   git clone https://github.com/zhenxishuai/ai-cognition-test.git
   cd ai-cognition-test
   ```
2. 直接用任何现代浏览器（Chrome、Edge、Safari 等）双击打开 `index.html` 即可运行。
   或使用本地静态服务器：
   ```bash
   npx serve .
   # 或
   python3 -m http.server 8080
   ```

## English

### 📖 Introduction
An interactive, engaging web-based **AI Cognition & Mastery Level Quiz**. Through practical and reflective scenarios, it helps you assess your depth of AI understanding, prompt engineering maturity, agent orchestration skills, and mental models in the generative AI era.

Built as a lightweight, zero-dependency, self-contained single-file HTML app.

### 💡 Inspiration: Karpathy's AI Cognition Funnel
Inspired by Andrej Karpathy's reflections on the cognitive progression of human-AI collaboration:
- **Novice / Casual User**: Treating AI as a slightly smarter search engine or conversational curiosity.
- **Practitioner**: Mastering prompt design and using LLMs daily for drafting, coding assistance, and synthesis.
- **Orchestrator**: Leveraging tool-use, MCP protocols, multi-model workflows, and retrieval systems with ease.
- **Architect**: Designing autonomous multi-agent systems and decomposing complex workflows into reliable agent loops.
- **Visionary / Master**: Deeply internalizing AI capabilities, cognitive limits, and reshaping organizational paradigms.

Where do you stand on the AI mastery ladder? Take the test to find out!

### 🚀 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/zhenxishuai/ai-cognition-test.git
   cd ai-cognition-test
   ```
2. Simply double-click `index.html` to open it in any modern browser.
   Or spin up a simple static server:
   ```bash
   npx serve .
   # or
   python3 -m http.server 8080
   ```
